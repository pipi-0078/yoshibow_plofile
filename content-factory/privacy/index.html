ヨシボウ コンテンツ制作・投稿ツール

制定日・最終更新日：2026年9月21日

本ポリシーは、ヨシボウ（以下「運営者」）が自身のコンテンツを制作し、自身のYouTubeチャンネルへ投稿するために使用する「ヨシボウ コンテンツ制作・投稿ツール」（以下「本ツール」）に適用されます。

利用者は運営者本人です。一般向けの利用登録やサービス提供は行っていません。中陰表・年忌表や仏教学習アプリについては、既存アプリのプライバシーポリシーをご確認ください。

1. Googleへの接続と許可

本ツールはYouTube API Servicesを利用します。Google OAuthにより、本人がGoogleの認証画面で許可したうえで接続します。

現在要求する権限は https://www.googleapis.com/auth/youtube です。この権限はYouTubeアカウントの管理に関わる広い権限を含みます。本ツールが行う操作は、以下に記載する投稿先の確認、非公開投稿、サムネイル設定、投稿結果の確認です。

Googleのパスワードを本ツールが取得・保存する仕組みではありません。

2. 取得する情報と利用目的

  • 投稿先の確認：本人のチャンネルID・チャンネル名などのチャンネル情報を取得し、予定した投稿先と一致するか照合します。
  • 認証の維持：アクセストークン、更新用トークン、有効期限などGoogleが返す認証情報を利用します。
  • 投稿後の確認：動画ID、動画URL、チャンネルID、タイトル、概要欄、公開設定、処理状況、サムネイルURLなどを取得し、送信した内容や非公開設定を確認します。

3. YouTubeへ送信する情報

本人が用意した動画ファイル、タイトル、概要欄、サムネイル画像をYouTubeへ送信します。あわせて、タグ、カテゴリ、言語、子ども向けかどうかの設定も送信します。

現在の投稿機能は非公開投稿のみを許可します。一般公開には、本人によるYouTube Studioなどでの別操作が必要です。

4. ローカルに保存する情報

アクセストークンと更新用トークンは、本人のローカル端末のリポジトリ外に保存します。標準の保存場所は、ホームディレクトリ内の .config/content-factory/youtube-private-upload-token.json です。認証情報ファイルの作成・更新時には、所有者だけが読み書きできるファイル権限を指定します。

投稿用の設定ファイルには、投稿先、動画・画像のパス、タイトル、概要欄などを記録します。投稿結果には、動画ID、動画URL、YouTube StudioのURL、投稿先、日時、公開設定、サムネイルURL、動画・画像のSHA-256ハッシュを記録します。ハッシュは、ファイルの一致を確かめるための値です。

投稿後の確認結果や、制作物を指定フォルダへコピーした際の保存先・ハッシュなども、コンテンツごとのローカルファイルに記録します。

現在の運用では、これらの認証情報・投稿記録のバックアップやクラウド同期は行っていません。

5. 保存期間と削除方法

認証情報や投稿記録には固定の保存期限を設けていません。投稿・確認に必要な間は保持し、不要になった時点で本人が手動で削除します。現在の実装には、一定期間後に自動削除する機能はありません。ローカルのファイルは、本人が削除するまで残ります。

  • 認証情報：利用を終了する際はGoogle側の連携を解除し、上記のトークンファイルを本人が削除します。保存先を変更している場合は、指定した保存先のファイルを削除します。不要になったOAuthクライアントの認証設定ファイルも別途削除します。
  • 投稿情報・記録：コンテンツごとの投稿用設定ファイル、投稿結果、確認結果、コピーの記録を本人が削除します。動画や画像の原本・コピーは、それぞれの保存先で別途削除します。
  • YouTube上の動画：YouTube Studioなどから本人が削除します。ローカルの認証情報や記録を削除しても、投稿済みの動画は削除されません。

6. Googleアカウントとの連携解除

Googleアカウントの「サードパーティとの接続」から、本ツールへのアクセス許可を取り消せます。

連携解除は、ローカルにあるファイルや投稿済み動画の削除とは別の操作です。再び接続する場合は、本人の再認証が必要になることがあります。

7. 外部への送信とGoogle APIデータの利用

認証・トークンの更新ではGoogleへ、投稿と投稿結果の確認ではGoogle／YouTubeへ通信します。Google側での情報の取り扱いには、Googleプライバシーポリシーが適用されます。

Google APIから受け取った情報は、ここに記載した投稿と確認の目的に限定して取り扱います。その利用および他のアプリへの転送は、Limited Use（制限付き利用）の要件を含むGoogle API Services User Data Policyに従います。

Google APIから取得した情報やトークンを、広告配信、販売、AIモデルの学習には利用しません。
